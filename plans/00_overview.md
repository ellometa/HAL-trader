# HAL — Project Overview

A personal tool that overlays a chatbot on TradingView. The user asks
questions about whatever chart they're looking at; the system answers
using deterministically-detected ICT features from real OHLC data,
grounded in the user's own trading notes from Notion.

## Why this design

- **No vision.** TradingView charts are just visualizations of OHLC.
  Asking a VLM to read pixels is strictly worse than feeding the model
  the raw numbers and a structured summary of geometric features
  (FVGs, order blocks, sweeps, BOS/CHoCH). This is the single most
  important architectural call.
- **Deterministic detectors, not ML.** ICT concepts are geometric rules
  on candles, not learned patterns. A 50-line Python function will
  match (or beat) any model on detection — and is debuggable.
- **No RAG yet.** Personal trading notes will be < 100k tokens. Stuff
  them in the system prompt. Add retrieval only if the corpus outgrows
  Gemini's window.
- **Local-only.** No auth, no deployment, no cloud. Runs on the user's
  laptop. This keeps the surface area tiny.

## Glossary

**ICT (Inner Circle Trader) concepts** — geometric patterns on price
charts used by a particular school of discretionary traders. All are
deterministic rules over OHLC.

- **OHLC** — Open, High, Low, Close. The four numbers that define one
  candle. Most data sources also include Volume and a timestamp.
- **Candle / bar** — one row of OHLC for one timeframe interval.
- **Timeframe** — the duration each candle covers (1m, 5m, 1h, 4h, 1D…).
- **FVG (Fair Value Gap)** — a 3-candle pattern where the wicks of
  candle 1 and candle 3 don't overlap, leaving a price "gap" through
  candle 2. Bullish FVG: low of candle 3 > high of candle 1. Bearish
  FVG: high of candle 3 < low of candle 1.
- **Order block** — the last opposing candle before a strong impulsive
  move. Bullish OB: last down-candle before a strong up-move that
  breaks structure. Bearish OB: mirror. Definitions vary; we'll lock
  one down in phase 2.
- **Liquidity sweep / stop hunt** — price spikes past a recent swing
  high/low (taking out stops resting there) and reverses.
- **BOS (Break of Structure)** — price closes beyond a prior swing
  high (bullish) or swing low (bearish), confirming trend continuation.
- **CHoCH (Change of Character)** — first BOS in the opposite direction
  of the prior trend; signals a potential reversal.
- **Swing high/low** — a candle whose high (low) is higher (lower) than
  the N candles on either side. We'll use N=2 by default.

**Tech terms**

- **Manifest V3** — current Chrome extension format. Service worker
  background script, stricter CSP, no remote code.
- **SSE (Server-Sent Events)** — one-way streaming over HTTP using
  `text/event-stream`. Simpler than WebSockets when the server only
  needs to push.
- **`google-genai`** — Google's *new* unified Python SDK for Gemini
  (released late 2024). Replaces `google-generativeai`. The two are
  not import-compatible; using the wrong one is the most common
  copy-paste bug in tutorials.

## Tech preferences (apply to every phase)

- Python 3.11+
- **`uv`** for dependency + virtualenv management (NOT pip + venv).
  `pyproject.toml` is the manifest; `uv sync` installs, `uv add <pkg>`
  adds, `uv run python ...` runs.
- `google-genai` (NOT `google-generativeai`)
- `fastapi`, `uvicorn`, `python-dotenv`, `httpx`, `yfinance`,
  `pandas`, `pytest`, `notion-client` (phase 5)
- Compatible-release pinning (`~=`)
- Vanilla JS extension, no React, no bundler. CSS class prefixes
  (`.hal-*`), no Shadow DOM in v0.
- `.env` for secrets, loaded via `python-dotenv`. `.env` gitignored
  from day one.
- Streaming end-to-end once phase 7 lands
- GitHub remote: `https://github.com/ellometa/HAL-trader.git`,
  branch `main`. Initialize git + push at the end of phase 1.

## Locked decisions

- **Deps:** uv + pyproject.toml, `~=` version pinning.
- **Notes file:** `backend/notes.md`.
- **Phase 2 scope:** FVG + Order Blocks only. Structure (BOS/CHoCH)
  and liquidity sweeps deferred to phase 8 polish.
- **Mitigated zones:** returned with `mitigated: true` flag, not
  filtered.
- **Swing N:** 2.
- **Notion SDK:** `notion-client`.
- **Extension styles:** CSS class prefixes (`.hal-*`).
- **Conversation history:** persisted in `chrome.storage.local`
  keyed by tab (phase 6).
- **Streaming meta:** first SSE `meta` event carries
  `features` + `current_price`.
- **Abort button:** deferred to phase 8 polish.
